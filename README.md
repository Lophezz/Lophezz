### 👨‍💻 Sobre Mim

Olá! Me chamo **Matheus Lopes**, sou um Desenvolvedor de Software de São Paulo - SP apaixonado por arquitetura de software, desenvolvimento mobile/web e resolução de problemas reais através da tecnologia.

- 🎓 Concluindo **Desenvolvimento de Software Multiplataforma** na **Fatec Mauá** (6º/6º semestre).
- 🏅 Graduado em **Análise e Desenvolvimento de Sistemas (ADS)** pela **Universidade Cruzeiro do Sul** e Técnico em Desenvolvimento de Sistemas pela **ETEC**.
- 🚀 Experiência prática no desenvolvimento de aplicações **Full-Stack e Mobile** utilizando **React Native (Expo), TypeScript, Java (Spring Boot), Node.js e Python**.
- 🗄️ Vivência com modelagem, consultas avançadas e integração de bancos de dados relacionais e não-relacionais (**SQL Server, PostgreSQL, MySQL, Supabase, MongoDB e Redis**), além de conectividade corporativa via **ODBC**.
- 🔒 Foco em boas práticas de arquitetura, **APIs RESTful**, autenticação **JWT**, controle de acesso (**RBAC**), acessibilidade digital e interfaces responsivas em *Dark Mode*.
